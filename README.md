# Repositorio-P0
Capacitação em Agentes de IA: P0 - Primeiro fluxo com LLM

O Projeto proposto nesse primeiro Repositório atende a a necessidade pontual de identificação, separação e renomeamento de laudos de fertilidade de solo em PDF emitido por diferentes laboratórios.

Para o desenvolvimento do proposto, ao executar o script em Python, o arquivo PDF deve ser lido, página à página. O texto extraído é enviado a LLM que por sua vez rastreia a identificação do laudo, que possui um padrão esperado, e retorna à aplicação em python para separação e renomeação de cada laudo.
